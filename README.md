# make-knowledge-cards

把用户粘贴的文章，或本地 Markdown / TXT 文件，整理成便于复习的知识卡片。

本项目是一份开源的智能体 Skill。行为说明以 `SKILL.md` 为准。OpenAI 类智能体还可以读取 `agents/openai.yaml` 中的界面元数据。

## 项目解决什么问题

读完一篇文章或一份笔记后，往往还要把真正重要的知识点抽出来，做成可以反复看的卡片。手工整理费时，也容易把过渡句、重复表述，或原文里根本没有的补充写进去。

这个 Skill 用来在对话里完成这件事：只依据用户提供的原文，抽出互不重复的重要知识点，写成结构统一的知识卡片，方便复习和记忆。

## 主要功能

- 接受两种输入：在对话里粘贴文章，或指定本地的 `.md` / `.txt` 文件
- 输出 5 到 8 张知识卡片；每张包含标题、核心知识、简明解释，以及一个例子或一道自测问题
- 只提取原文里真正重要、互不重复的知识点；一卡只写一个点，不编造原文没有的事实、例子、数字或建议
- 原文信息不足时，卡片可以少于 5 张，并说明原因，而不会为了凑数硬写
- 卡片语言和字段标签与原文保持一致；中文原文使用「核心知识」「简明解释」，以及「例子」或「自测」
- 对结构完整的长文，先给出最重要的 5 到 8 张作为总览；需要时再按章节继续做分套卡片
- 默认在对话里用 Markdown 给出卡片；如果用户需要，也可以写成本地 Markdown 文件

本 Skill 不支持把网页链接当作输入去抓取内容，也不支持直接读取 PDF、导出 Anki 或其他闪卡包，以及提供图形界面。如果只有链接或 PDF，请先把文本粘贴出来，或另存为 `.md` / `.txt` 后再使用。

## 安装方法

本项目不是需要编译或用包管理器安装的程序。把整个 `make-knowledge-cards` 文件夹复制到智能体加载技能的目录中即可。复制后的路径应类似：

```text
skills/make-knowledge-cards/
├── SKILL.md
├── agents/
│   └── openai.yaml
├── README.md
└── LICENSE
```

复制完成后，按所用智能体的方式启用或引用该 Skill。修改行为时请先改 `SKILL.md`，再视需要同步 `agents/openai.yaml`。

本项目不包含需要单独安装的脚本，也不依赖持续集成。

## 使用方法

用下面两种方式之一提供材料：

1. 直接把文章粘贴到对话里，并说明要做成知识卡片。
2. 指出本地的 `.md` 或 `.txt` 文件路径，让智能体读取后制卡。

如果同时提供了粘贴文本和文件，默认使用粘贴的文本，除非明确要求使用文件。输入可以是中文或英文。

关于卡片数量：

- 内容充实的文章：通常会得到 5 到 8 张卡片。
- 内容很少的笔记：卡片数可以少于 5 张，并会说明原因。
- 结构完整的长文：先给出最重要的 5 到 8 张作为总览，如需按章节继续拆，可以直接说。

## 输入输出示例

下面是一段可以粘贴使用的短文，以及按本 Skill 规则整理出的卡片。

**输入：**

肥皂洗手为什么比只用清水更有效？清水可以把手上看得见的污渍冲走，但对许多微生物帮助有限。这些微生物的外层往往带有油脂，不容易溶解在水里，于是会继续附着在皮肤上。

肥皂分子有两端：一端亲水，一端亲油。亲油的一端能插入微生物外层的油脂中，把它们从皮肤上“拉”下来，再随水流走。洗手时还需要足够的时间把肥皂揉开，并覆盖指缝、指尖和拇指这些容易被忽略的位置。常见建议是至少揉搓大约 20 秒。冲净肥皂后把双手擦干也很重要，因为潮湿的皮肤更容易再次沾上污物。

肥皂可以减少手上的微生物数量，但并不能消灭环境中的所有病原体，也不能代替在需要时使用的其他防护措施。

**输出：**

### 1. 清水难带走带油脂的微生物

**核心知识：** 清水能冲走可见污渍，但许多微生物外层带有油脂，不易溶于水，仍会附着在皮肤上。
**简明解释：** 洗手的目标不只是去掉看得见的脏东西。对带油脂外层的微生物来说，水本身不是好的溶剂，所以只用水往往冲不干净。
**自测：** 为什么只用清水洗手，对许多微生物的效果有限？

### 2. 肥皂分子同时亲水和亲油

**核心知识：** 肥皂分子一端亲水、一端亲油，亲油端能插入微生物外层的油脂，把它们从皮肤上带走并随水冲走。
**简明解释：** 肥皂起作用的关键是分子结构：一端抓住油脂，一端留在水里，于是微生物可以被“拉”离皮肤，再被水流带走。
**例子：** 文中把这一过程写成亲油端插入油脂，再把微生物从皮肤上拉下来。

### 3. 要覆盖容易被忽略的部位

**核心知识：** 洗手时需要把肥皂揉开，并覆盖指缝、指尖和拇指这些容易被忽略的位置。
**简明解释：** 只在手掌上打出泡沫是不够的。微生物可以留在细节部位，这些位置需要被明确照顾到。
**自测：** 文中提到哪些洗手时容易被忽略的位置？

### 4. 揉搓时间大约 20 秒

**核心知识：** 常见建议是至少揉搓大约 20 秒，好让肥皂充分起作用。
**简明解释：** 时间本身不是仪式，而是为了把肥皂揉开并接触到需要清洁的皮肤表面。时间过短，覆盖和接触都会不足。
**例子：** 原文给出的常见建议是至少揉搓大约 20 秒。

### 5. 擦干双手，以免再次沾上污物

**核心知识：** 冲净肥皂后把双手擦干很重要，因为潮湿的皮肤更容易再次沾上污物。
**简明解释：** 洗手在冲净之后还没有结束。残留的水分会让皮肤更容易重新带上脏东西，所以要擦干。
**自测：** 为什么洗手后还要把双手擦干？

### 6. 肥皂不能代替所有防护

**核心知识：** 肥皂可以减少手上的微生物数量，但不能消灭环境中的所有病原体，也不能代替在需要时使用的其他防护措施。
**简明解释：** 肥皂洗手有明确效果，也有明确边界。它降低的是手上的微生物数量，而不是提供一种万能防护。
**自测：** 原文如何限定肥皂洗手的作用范围？

卡片：6 张（原文信息足够，未凑数，也未超出原文）。
